# The Little Match Girl — Unity

Mobile-first six-page interactive storybook for Unity WebGL.

## Pages
1. Home
2. Scene 1 — A Winter Street
3. Scene 2 — The First Match
4. Scene 3 — The Second Match
5. Scene 4 — The Final Match
6. Credits

## Features
- Portrait/mobile-first UI
- Uniform Back / Home / Next buttons
- Animated snow
- Story interaction on every story page
- Visual feedback panel
- Runtime-generated sound feedback
- Automatic scene creation
- WebGL build menu

## Unity version
Unity 2022.3 LTS.

## Open locally
Open the repository folder in Unity Hub. On first import, `Assets/Main.unity` is generated automatically. If needed, use:

`Tools > Little Match Girl > Rebuild Main Scene`

## Build WebGL locally
Install WebGL Build Support, then use:

`Tools > Little Match Girl > Build WebGL`

The output is written to `WebGLBuild`.

## Unity Build Automation
Use branch `main`, Unity 2022.3 LTS, and target platform `WebGL`.
